# 阶段 B 审查报告

## 发现

### [P1] 错误脱敏未覆盖完整账号 ID

位置：`codex_widget/app_server_quota_reader.py:312`

阶段 B 验收标准明确要求“错误消息不包含 token、完整账号 ID、邮箱或 bearer header”（任务书第 102 行）。当前 `_redact()` 只调用了 bearer、邮箱和部分 token 形态的脱敏函数，未覆盖账号 ID 形态。JSON-RPC error、stderr 退出信息和启动/写入异常都会把 `_redact(str(...))` 后的文本拼进 `AppServerQuotaError`，因此只要上游错误中包含完整账号 ID，就会原样暴露。

用伪造数据验证：

```powershell
uv run python -c "from codex_widget.app_server_quota_reader import _redact; s='auth failed for account account_1234567890abcdef and acct_abcdef1234567890'; print(_redact(s))"
```

输出仍保留完整伪造账号 ID：

```text
auth failed for account account_1234567890abcdef and acct_abcdef1234567890
```

对应测试也缺少账号 ID 脱敏断言；当前只覆盖了邮箱、bearer、`sk`/`sess` 等 token 片段：`tests/test_app_server_quota_reader.py:134`。

## 已验证

```powershell
uv run pytest tests/test_app_server_quota_reader.py
```

结果：10 passed。

## 返工建议

补充账号 ID 脱敏规则和对应测试，至少覆盖 JSON-RPC error、stderr 退出信息、启动/写入异常中的伪造完整账号 ID。
